# music/

Drop your own ripped albums here — one folder per album, e.g.:

```
music/
  Green Day - Dookie/
    01 Burnout.mp3
    02 Having a Blast.mp3
    ...
```

Navidrome scans this folder automatically (hourly, or trigger a scan from its
own web UI at http://localhost:4533). Files need proper ID3 tags (artist,
album, title) for Vinyl Depot's "Přehrát" match-by-title lookup to find them.
